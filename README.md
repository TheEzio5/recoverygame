# Recovery Quest

A recovery-focused life simulation.

- Play in a terminal: `python recovery_main.py`
- Touch version (Kivy): `python main.py` - menus become picture tiles, typing is only used for names and amounts
- Tests: `python -m unittest discover -s tests`
- Re-draw the pictures: `python tools/make_art.py` (needs Pillow)

Your save file (`player_save.json`) is personal and is ignored by Git.
